# Buyora legal pages

Static Privacy Policy, Terms of Service and account-deletion pages for the Buyora apps.
Plain HTML + one CSS file in `public/`; no scripts, trackers or cookies.

Live: https://buyora-legal.web.app

Deploy (Firebase Hosting site `buyora-legal`, project `buyora-b8586`):

```
npx.cmd firebase-tools deploy --only hosting:legal --project buyora-b8586
```
